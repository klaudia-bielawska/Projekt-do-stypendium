# Projekt-do-stypendium
Projekt do stypendium. <br>
W tym repozytorium są zawarte wszystkie pliki, które są potrzebne do odpowiedniego funkcjonowania strony.
Są animacje oraz jest dużo obrazów, które się zmieniają do czego był mi potrzebny skrypt w JavaScript. Podstawowy kod głównej strony oraz podstron jest napisany w HTML, a upiększenie graficzne w CSS.

Jest również plik Wszystkie funkcje strony.mp4, który pokazuje wszystkie możliwości strony.
