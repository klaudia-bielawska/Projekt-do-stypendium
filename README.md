# Projekt-do-stypendium
Projekt do stypendium. <br>
W tym repozytorium są zawarte wszystkie pliki, które są potrzebne do odpowiedniego funkcjonowania strony. <br>
Są <b>animacje</b> oraz jest dużo obrazów, które się zmieniają do czego był mi potrzebny skrypt w <b>JavaScript</b>. Podstawowy kod głównej strony oraz podstron jest napisany w <b>HTML</b>, a upiększenie graficzne w <b>CSS</b>.

Jest również plik Wszystkie funkcje strony.mp4, który pokazuje wszystkie możliwości strony.
